GOOD TO KNOW

Quick answers.

Can I play in my browser?

This site introduces the project. The games run in the Windows desktop app, not on GitHub Pages.

Does it need an account?

No account is required. The games are played locally on your PC.

Where are my records stored?

Game records and preferences are saved in your Windows LocalApplicationData folder.
